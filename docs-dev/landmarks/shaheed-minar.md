# Shaheed Minar asset — placement pending

`buildShaheedMinar({heightMeters})` builds a local-origin, one-mesh reference-inspired asset: five open frames, paired central uprights, physical fine bars, red disc and stepped reddish plaza. Caller height is mandatory because actual height is unknown. All proportions are provisional. It adds no colliders and does not mutate input. `dispose()` is idempotent.

Sources: [front view](https://commons.wikimedia.org/wiki/File:Shahid_Minar_IU.jpg) and [group view](https://commons.wikimedia.org/wiki/File:Shahid_minar_and_Monument.jpg). BTV platform dimensions remain reported and have not been converted into measured model scale. The photo's geographic point identifies the camera, not the monument. Sources establish a search region south of the gate but no safe production anchor/orientation.

The function is not called by the campus world until placement is verified. Task 6 is therefore partial: geometry and four tests are ready; location/physical-dimension acceptance remains pending. Standard build passes. This asset is distinct from the red-brick memorial.
