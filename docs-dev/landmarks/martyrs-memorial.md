# Brick memorial asset — placement pending

`buildMartyrsMemorial({heightMeters})` creates an unplaced local-origin reference-inspired model distinct from the Minar. It has a thick curved barrel-vault-like outer shell, nested open portal layers and pale curved relief-wing bases. One merged mesh, no colliders; height is mandatory and proportions are explicitly provisional. Disposal is idempotent.

Sources: [front](https://commons.wikimedia.org/wiki/File:Shahid_Monument,_Islamic_University,_Bangladesh.jpg), [aerial](https://commons.wikimedia.org/wiki/File:Shahid_Monument,_architectures_of_Islamic_University,_Bangladesh.jpg). The shell has real depth/soffit rather than an opaque or zero-thickness arch face. Exact inscriptions/reliefs are not copied or claimed complete.

Task 7 remains partial: geometry/four focused tests are ready, while absolute anchor, orientation and physical scale require a verified site reference. No production placement is activated. The existing application build remains valid; no runtime imports, source OSM or collision geometry change in this task.
