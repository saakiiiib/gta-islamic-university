# Central Mosque approximation

The dedicated model targets OSM way 1317423259. It adds a large dome/octagonal drum, a shallow secondary dome, four low cupolas and hollow facade arches to the retained OSM body. It uses one merged vertex-color mesh (under 20,000 triangles), keeps the source footprint/collision unchanged, and disposes its owned resources exactly once. Generic rectangular windows are suppressed for this building. Ground-level arch centers have no added decorative infill or collision.

Sources: [2021 aerial](https://commons.wikimedia.org/wiki/File:Central_Mosque_architectures_of_Islamic_University,_Bangladesh.jpg), [2021 roof view](https://commons.wikimedia.org/wiki/File:Islamic_University_Central_Mosque_main_dome_and_others.jpg), [four-storey/90-foot dome report](https://thedailycampus.com/public-university/138124). The registry records historical colors and the reported storey count; its heightMeters remains unknown. The generic body envelope is retained.

The 27.4 m dome-top parameter is a provisional ground-to-finial interpretation of a reported 90-foot dimension with an unspecified datum. Dome/cupola centers and exact arch rhythms are illustrative fits inside the mapped footprint, not a surveyed roof plan. Four small cupolas are not the planned 150-foot minarets; no such tall minarets are built. These limitations are available in model diagnostics.

Verification: finite/bounded geometry, roof containment, no added colliders, hollow entry frames, immutability, deterministic options and idempotent disposal have focused tests. Full suite passed during integration (263 tests, including a not-yet-integrated auditorium module); after final upper-arch shading, the six mosque tests and standard build passed again. A computed geometry preview was visually checked. Interactive browser/mobile visual validation remains pending because the current browser control connection is unavailable; this is not presented as a verified in-game screenshot.
