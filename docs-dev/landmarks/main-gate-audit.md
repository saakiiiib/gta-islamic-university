# Main-gate reference audit

A newly checked [21 February 2013 front view](https://commons.wikimedia.org/wiki/File:Islamic_University_Bangladesh,_Islamic_Unviersity_gate,_iu_gate.jpg), Shohan6, CC BY-SA 3.0, confirms **four arches**: two large vehicle arches and two small side arches. The earlier three-portal reading from the oblique aerial was wrong; campus-realism.md is corrected and the new photograph/author/license/hash are registered. The existing game model already has the right count.
